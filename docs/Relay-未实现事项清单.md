## 一、核心系统（优先级：高）

- [ ] **程序栈和数据栈的持久化** - 当前使用 CompoundTag 临时存储，需改用 26.1.2 的 ValueOutput/ValueInput
- [ ] **程序加载反转逻辑** - `loadProgram()` 方法需实现列表反转后压入

- [ ] **操作数预算机制** - `remainingOps` 计数和每 Tick 重置
- [ ] **事故处理机制** - `triggerMishap()` 清空双栈并终止
- [ ] **栈大小限制检查** - 默认 1024，可配置

### 1.2 操作注册表 (OperationRegistry)
- [ ] **操作签名系统** - 类型签名用于编辑器类型推导

- [ ] **世界交互器检查** - `.requiresWorldInteractor()` 标记
- [ ] **已实现操作**：
  - [x] 基础操作：Push, Pop, Dup, Swap
  - [x] 算术操作：Add, Sub, Mul, Div
  - [x] 逻辑操作：And, Or, Not
  - [x] 比较操作：Eq, Lt, Gt
  - [x] 控制流：Eval, If
  - [x] 通信操作：Send, Recv, Peek
  - [ ] **列表操作** - Get, Set, Length, Append, Concat
  - [ ] **向量操作** - VecAdd, VecSub, VecMul, VecDot
  - [ ] **实体操作** - GetEntityPos, GetEntityHealth, SelectEntity
  - [ ] **世界交互操作** - PlaceBlock, BreakBlock, UseItem

### 1.3 通信系统 (CommunicationSystem)
- [x] 全局频道 Map
- [x] send/recv/peek 操作
- [ ] **队列容量限制检查** - 1000 超出触发事故
- [ ] **跨维度路由** - 当前为全局共享，需确认是否需要维度隔离选项
