# Relay 法术编辑器使用指南

## 启动编辑器

1. 放置 **法术编辑器方块** (`spell_editor_block`)
2. 右键点击方块打开编辑器 GUI

## GUI 布局

```
┌─────────────────────────────────────────────────────┐

│             │             │                         │

```

## 可用操作列表

### 基础栈操作
| 操作名 | 功能 | 签名 |
|--------|------|------|
| `push` | 压入值到数据栈 | `data: any → --` |
| `pop` | 弹出栈顶值 | `-- data: any` |
| `dup` | 复制栈顶值 | `a -- a a` |
| `swap` | 交换栈顶两个值 | `a b -- b a` |

### 算术操作
| 操作名 | 功能 | 签名 |
|--------|------|------|
| `add` | 加法 | `a b -- a+b` |
| `sub` | 减法 | `a b -- a-b` |
| `mul` | 乘法 | `a b -- a*b` |
| `div` | 除法 | `a b -- a/b` |

### 逻辑操作
| 操作名 | 功能 | 签名 |
|--------|------|------|
| `and` | 逻辑与 | `a b -- a∧b` |
| `or` | 逻辑或 | `a b -- a∨b` |
| `not` | 逻辑非 | `a -- ¬a` |

### 比较操作
| 操作名 | 功能 | 签名 |
|--------|------|------|
| `eq` | 等于 | `a b -- a==b` |
| `lt` | 小于 | `a b -- a<b` |
| `gt` | 大于 | `a b -- a>b` |

### 控制流
| 操作名 | 功能 | 签名 |
|--------|------|------|
| `eval` | 执行列表 | `list --` |
| `if` | 条件分支 | `cond then-list else-list --` |
| `stop` | 停止执行 | `--` |

### 通信操作
| 操作名 | 功能 | 签名 |
|--------|------|------|
| `send` | 发送到频道 | `channel data --` |
| `recv` | 从频道接收 | `channel -- data` |
| `peek` | 查看频道 | `channel -- channel data` |

### 列表操作
| 操作名 | 功能 | 签名 |
|--------|------|------|
| `list_append` | 追加元素 | `list elem -- list` |
| `list_get` | 获取元素 | `list index -- elem` |
| `list_set` | 设置元素 | `list index elem -- list` |
| `list_length` | 获取长度 | `list -- length` |

### 世界交互
| 操作名 | 功能 | 签名 |
|--------|------|------|
| `get_block` | 获取方块 | `pos -- block` |
| `place_block` | 放置方块 | `pos block --` |

## 编写程序示例

### 示例 1: 简单加法 (2 + 3)

```
程序序列:
1. push (2)     # 压入 2
2. push (3)     # 压入 3
3. add          # 执行加法

执行过程:
数据栈：[] → [2] → [2, 3] → [5]
```

### 示例 2: 复合运算 ((2 + 3) * 4)

```
程序序列:
1. push (2)
2. push (3)
3. add          # 2 + 3 = 5
4. push (4)
5. mul          # 5 * 4 = 20

数据栈变化:
[] → [2] → [2,3] → [5] → [5,4] → [20]
```

### 示例 3: 条件执行

```
程序序列:
1. push (true)           # 条件
2. push ([push(1)])      # then 分支
3. push ([push(0)])      # else 分支
4. if                    # 执行 then 分支，栈顶变为 1

数据栈：[] → [true] → [true, [1]] → [true, [1], [0]] → [1]
```

### 示例 4: 循环（使用 eval 和列表）

```
# 计数循环：打印 5 次
程序序列:
1. push (5)              # 计数器
2. push ([               # 循环体列表
    dup                  # 复制计数器
    push (1) sub         # 减 1
    dup                  # 再复制
    push (0) gt          # 检查是否 > 0
    push ([              # 如果 > 0，继续循环
        # 这里可以添加要重复的操作
    ])
    if
])
3. eval                  # 执行列表
```

## 调试技巧

1. 观察 **数据栈** 面板查看当前值
2. 观察 **程序栈** 面板查看执行进度
3. 查看 **事故** 提示了解错误原因
4. 使用 **清空** 按钮重置程序
5. 使用 **删除** 按钮移除选中的程序项
